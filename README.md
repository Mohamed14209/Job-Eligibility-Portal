# 💼 Job Eligibility Portal

A command-line job application screener built with pure Python — checks a candidate's answers against basic eligibility rules.

بوابة بسيطة لفحص أهلية المتقدم لوظيفة: بتسأله كذا سؤال وبعدين تقرر لو مؤهل يكمل لمرحلة الإنترفيوهات ولا لأ.

---

## ✨ Features

- Collects candidate info: Python knowledge, years of experience, number of projects, and educational background
- Input validation for numeric fields (experience & project count)
- Two acceptance paths:
  - Knows Python **and** has a degree/bootcamp → accepted
  - Knows Python **and** has 2+ years experience **or** 2+ projects → accepted
- Clear accept/reject message at the end

## 🚀 How to Run

```bash
git clone https://github.com/Mohamed14209/Job-Eligibility-Portal.git
cd Job-Eligibility-Portal
python "Job Eligibility Portal.py"
```
